The most important gaps and fixes that can be developed without GTA running:

1. **High — action safety/truthfulness checks are incomplete.** Dialogue can claim completion before any acknowledgment, and Python does not reauthorize queued actions at delivery. Add acknowledgment-aware sentence checks in `runtime.py`/`runtime_speech.py`, refresh action-stage eligibility, and recheck policy in `app.py` command polling. Add adversarial completion-claim and stale/changed-state tests in `test_bridge.py`/`test_runtime_speech.py`. The C# dispatch guard remains protective; no native permission or storyline bypass was demonstrated.
2. **High — session-erasure acceptance fails under Windows load.** The reproduced 36-NPC/200-turn test fails at `storage.py:481` during session close, before verifying ephemeral-memory cleanup. Investigate the isolated subprocess's writable SQLite/temp environment and directory lifetime in `test_simulated_load.py`/`tools/simulated_load.py`; add a focused large-delete/close regression and explicit cleanup-failure handling in `runtime.py`. Root cause and cross-session exposure are not established; this is a privacy-retention verification failure.
3. **Medium — persistent characters are mostly content, not live characters.** Implement a fake-testable curated spawn/reconciliation controller in `LivingNPC.Core`, native-model/anchor transport in `GtaGameAdapter.cs`, and actor-specific voice resolution in `speech_coordinator.py`. Correct the in-place pin promotion in `storage.py`/`runtime_pin.py` to create a new durable UUID. Test three simulated reloads, duplicate prevention, pin lineage and two-character voice routing.
4. **Medium — production perception, bystanders and triggers are disconnected.** Extend `protocol.py`, `LivingNpcScript.cs`, `GtaGameAdapter.cs`, `context.py` and `runtime.py` with conservative nullable sensor/observer contracts; expose hearing radii in `settings.py`. Add the explicit 20-case visibility matrix, false-positive/miss reporting, configurable-radius tests and trigger-to-speech integration tests.
5. **Medium — the P0 action suite is incomplete.** Only development face/wait executors exist; release advertises none. Implement fake-testable follow/stop/safe-point/wander/flee state machines and explicit locomotion consent in `ConversationInput.cs`/`runtime_speech.py`. Add registry preconditions, complete denial records and a generated 100-candidate cross-policy/adapter corpus. Keep native activation gated until rig proof.
6. **Medium — required interaction controls are missing or different.** Add look-based selection, a persistent target label, explicit cancel/selection clearing and delivered-turn history in Core/`LivingNpcScript.cs`; add mic/voice tests and authored-trigger inspection in `admin.py`/`dashboard.html`. Test candidate ordering, cancellation, state transitions, bounded history and device teardown.
7. **Medium — selective memory and dashboard Create are missing.** Add a deterministic salience/retention policy in `runtime.py` and provenance-bearing authored-memory creation in `admin.py`/`dashboard.html`. Test low-value versus significant events, scope/erasure and rejection of fabricated eyewitness provenance. Background diaries remain P1, not an alpha blocker.
8. **Medium — configuration and diagnostics are incomplete.** Add versioned configuration migration to `settings.py`/`gateway.py` and an extracted strict adapter settings parser; add bounded redacted crash records and linked retrieval inspection to `admin.py`/`dashboard.html`. Test old versions, unknown keys, secret exclusion, authorization and erasure.
9. **Medium — deployment regression evidence is invalid.** The reproduced corrupt-upload test targets nonexistent `LivingNPC.pdb`; actual uploads use `LivingNPC.GameAdapter.pdb`/`LivingNPC.Core.pdb`. Fix `tools/tests/test_deploy_adapter.py` to corrupt a real catalog member and assert that corruption occurred; separately exercise checksum rejection and locked-DLL rollback. This failure does **not** prove production deployment accepted corrupted bytes.

P0 is alpha scope. P1 is explicitly “immediately after” alpha (`SPECS.md:196`); P2/NPC-to-NPC scenes, rumor propagation, spatial speech, lip sync, Enhanced and city-scale work are deferred. Their prototypes do not substitute for missing alpha integration. No confirmed secret leak, hot-mic behavior or storyline-protection bypass was found in the audited paths.
