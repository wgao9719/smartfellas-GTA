The ten most important gaps and fixes that can be implemented without GTA:

1. **High — cloud payloads lack secret/PII minimization.** Input, persona, memories and embedding text are serialized unchanged. Add shared cloud egress filtering in `service/lls/providers.py`, `service/lls/embeddings.py` and context construction; add MockTransport tests covering synthetic secrets in dialogue/action/embedding/social/skill payloads.
2. **High — two required safety stops are incomplete.** Repeated native-command failures do not stop dispatch; a schema mismatch rejects only that command. Add latched failure/protocol stops to `adapter/LivingNPC.Core/CommandController.cs`, preserving engine-owned tasks. Add `NativeFailuresLatchAndCancelPendingActions` and `SchemaMismatchCancelsAllPendingActions` fake-game tests.
3. **High — credential storage and CI security controls fall short.** Remove plaintext INI token fallback from `adapter/LivingNPC.GameAdapter/LivingNpcScript.cs`/`adapter/LivingNPC.GameAdapter/LivingNPC.ini.example`, or use Windows Credential Manager; test credential resolution. Add a pinned secret scanner to `.github/workflows/ci.yml` with synthetic detection fixtures. No real credential exposure was demonstrated.
4. **High — short local transcript/event retention is not implemented.** Add explicit retention settings and a clock-driven purge in `service/lls/settings.py`, `service/lls/storage.py` and runtime maintenance, preserving deliberately durable memories and their necessary provenance. Test expiry, derived indexes and exports. Also add the missing actor-scoped export endpoint/UI and isolation tests.
5. **Medium — native alpha prerequisites are missing.** Add testable curated/pinned reconstruction, gated follow/stop execution, bounded vicinity/witness sampling and per-actor voice selection in `LivingNPC.Core`, `adapter/LivingNPC.GameAdapter/GtaGameAdapter.cs` and `service/lls/speech_coordinator.py`. Use fake sensors/tasks/voice providers for identity, occlusion, hearing, cancellation and ownership tests; keep native capabilities unverified until rig proof.
6. **Medium — tracing and budget instrumentation cannot produce the required acceptance evidence.** Extend `service/lls/runtime.py`, `service/lls/runtime_speech.py`, `service/lls/admin.py`, `service/lls/replay.py` and adapter diagnostics with scene/correlation/model IDs, stage timestamps, bounded tick histograms and a sanitized per-turn exporter. Test export→replay and privacy. Add unchanged-input throttling, scene accounting and a bounded summarizer.
7. **Medium — deployment regression and release CI are incomplete.** Fix `tools/tests/test_deploy_adapter.py:290` to corrupt an actual bundle member and assert corruption occurred; split checksum/locked-DLL cases. The current `LivingNPC.pdb` target is never uploaded. Add format/type checks and a Windows launcher/package/checksum job; test installation against temporary directories. Investigate the separately reported load-subprocess environment failure without weakening its assertions.
8. **Medium — configuration and schema deliverables are incomplete.** Add strict YAML/env interpolation and selected-provider startup validation in `service/lls/settings.py`; expose intended pack/world/action controls safely. Add `tools/export_schemas.py`, shared schemas and generated valid/invalid Python/C# fixtures with CI drift tests.
9. **Medium — scenario/evaluation evidence is missing.** Turn LLS-010 into at least twenty annotated fixtures; add a blinded seven-dimension scorer and separate hard-failure ledger, including fabricated-memory bait. Add per-ticket evidence records for LLS-001–013; leave G0/G1 results and footage pending until actually observed.
