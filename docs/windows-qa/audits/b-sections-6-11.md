The ten most important gaps and fixes that can be implemented without GTA:

1. **High — Save/profile privacy isolation is bypassed at startup.** The adapter silently uses profile “default” without a save association or change warning. Update LivingNpcScript.cs, both session DTOs, runtime.py and admin profile selection to require explicit association before memory attachment. Add first-load, different-slot/equal-time and rejected-reassociation tests.
2. **High — Failed session cleanup becomes non-retryable.** The Windows 36-NPC/200-turn test fails in storage.py:481 during close. runtime.py marks the session closed before that purge; an injected-failure probe confirmed later close skips retry. Add a closing/cleanup-pending state and idempotent retry in runtime.py/storage.py; isolate the Windows SQLite/temp-path cause in test_simulated_load.py without assuming it is a production database-path bug.
3. **High — Ordinary action cancellation can leave owned native work running.** CommandController.Tick forgets an action on distance loss without releasing its still-owned task. Split safe release from mission takeover/rebinding, retaining the latter's no-clear behavior. Add range-loss, user-cancel, ownership-change and ACK-backpressure tests. Current native exposure is Debug-only face/wait, bounded to five seconds.
4. **Medium — Command polling can exceed both wire and adapter queue limits.** A valid response measured 346,977 bytes/80 commands; the adapter accepts 256 KiB/64 commands. Paginate app.py responses by bytes and count, preserve cursor semantics, and test backlog draining in BridgeTests. Schedule heartbeat independently of event backlog.
5. **Medium — Required P0 action behavior remains unfinished.** Follow/stop/navigation/wander/flee have no native executors; face/wait are Debug prototypes, and gesture remains conditionally disabled. Implement deterministic controllers, ownership/stop contracts and fake-game tests in LivingNPC.Core; keep native enablement gated. Make registry cooldown/precondition policy consistent across Python/C#.
6. **Medium — Curated cast cannot reconnect into the game.** Add a pure tag/spawn/rebind reconciliation planner, IGameAdapter operations and duplicate/wanted/mission/generation fixtures. Update packs.py to admit validated spawn/voice assets and add a licensed actor-to-voice registry. Native spawn anchors and voice quality still require later rig checks.
7. **Medium — Wire compatibility and durable audit records are incomplete.** The spec's event/proposal examples fail validation; commands omit schema_version; optional features are not negotiated; manifests and full turn/action histories are not durable. Update protocol.py, C# DTOs, runtime.py and storage.py; add cross-language fixtures, proposal-wrapper correlation, restart/export and privacy-erasure tests.
8. **Medium — Speech timing and conversation context diverge from the turn pipeline.** Action selection waits for audio completion; recent transcript, participants and scene state are missing. Add a bounded speech queue in runtime_speech.py/speech_coordinator.py, separate model/playback deadlines, and bounded scene context in runtime.py/context.py. Test selector progress during blocked playback and cross-actor isolation.
9. **Medium — Memory consolidation, correction propagation and truth ranking are incomplete.** Add bounded per-turn candidates, near-duplicate/source diversity in memory_index.py, dependent-summary invalidation in storage.py, and explicit source precedence in providers.py/context.py. Test paraphrases, corrected summaries, contradictory hearsay/world facts and deletion races.
10. **Medium — Periodic recovery snapshots are missing.** Only manual backup exists. Add configurable, bounded scheduled snapshots in settings.py/runtime.py/storage.py with atomic publication and rotation. Test restoration and backup failure using fake time and temporary databases.
