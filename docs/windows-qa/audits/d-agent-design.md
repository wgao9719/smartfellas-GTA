# Agent-design conformance audit

## 1. Summary

Audited the complete `references/SPECS_agentdesign.md` against branch `living-los-santos-foundation`, commit `7aeabaa`, on TOWER-PENGU (2026-10-11). **The implementation does not yet conform fully.** Its closed action vocabulary and scoped storage provide substantial protection, but cleanup, dialogue grounding, and actor/location clearance have High-severity gaps.

These count requirement rows, not unique defects; the same cancellation defect violates two separately stated requirements. **798 targeted Python tests passed** in this audit. C# tests were inspected, not rerun. No GTA, native audio, real model, or in-game acceptance check was performed.

The most important gaps and fixes that can be prepared and tested without GTA are:

1. **G1 — High: cancellation can clear a newly protected actor's task.** `CancelInput` can invoke `CommandController.Cancel` before the safer Tick path; Cancel omits protection/unknown-ownership/generation checks, and native release uses `ClearAll`. Centralize the full current-state predicate in `adapter/LivingNPC.Core/CommandController.cs` and revalidate release in `adapter/LivingNPC.GameAdapter/GtaGameAdapter.cs`. Add `ControllerTests` for protection, ownership and generation changes immediately before direct cancellation. This is a code-review finding on the opt-in development native-action path, not observed mission corruption.

2. **G2 — High: prohibited narrative claims reach delivery.** An in-memory fake-provider probe queued an invented Lester mission, cash reward and permanent shop discount unchanged; it queued zero native actions. Add precomputed grounded intents and a sentence-level delivery gate, preserving FR-DLG-02 plain-text streaming, in `service/lls/runtime.py`, `providers.py`, `social.py` and `runtime_social.py`, with a deterministic neutral fallback. Add adversarial tests in `tests/test_bridge.py` and `tests/test_runtime_social.py` covering mission, plot, service, canonical-relationship and completed-event claims.

3. **G3 — High: actor/location eligibility is incomplete.** Release omits owning-script sampling; Busy does not prove that services, encounters, scripted animations, escorts or essential tasks are idle, and no location-clearance contract exists. Add explicit known/unknown clearance evidence to `protocol.py`, adapter `GameState.cs`/`GtaGameAdapter.cs`, and both policy layers. Add fixtures that deny dialogue, pinning and actions when clearance is unknown or restricted. Native sampling accuracy still needs the rig.

4. **G4 — Medium: retelling requires unqualified original words.** A first-person observation can become the reteller's own spoken eyewitness claim even though stored metadata remains reported. Change `social_storage.py` and `social.py` to render a deterministic teller-qualified quotation while retaining the exact underlying quote. Add a two-hop “I saw Franklin…” regression in `tests/test_social.py`. This implemented feature is post-v1.

5. **G5 — Medium: manual skill trials skip simulated preflight.** Reuse the automatic scheduler's preflight in `runtime_skills.py`, persist a candidate/dependency validation fingerprint, and require it before any bridge trial. Add direct-route, failed-preflight and changed-dependency tests in `tests/test_runtime_skills.py`. This is a post-v1 lifecycle gap; primitive authorization is still enforced.

6. **G6 — Medium: skill retention measures mechanical completion, not useful social outcomes.** Refusal/cancellation cannot qualify for adoption; relevance, repetition and participant response are not evaluated, and role/effect/resource metadata is incomplete. Extend `skills.py`, `skill_store.py` and `skill_scheduler.py` with derived permission manifests and typed observed evaluation evidence. Test appropriate refusal, repetition avoidance and rejection of self-awarded satisfaction. This is post-v1 work.

7. **G7 — Medium: persistent storage is not persistent native identity.** Pinning survives database/session closure, but the adapter does not re-embody/reconcile those saved identities after restart. Implement a pure reconciliation planner and tests around `storage.py`, `runtime_pin.py` and the adapter binding layer for one identity/one incarnation, unavailable actors and earlier saves; keep native creation disabled pending validation. Do not classify this missing integration as only a rig test.

8. **G8 — Medium: limits do not cover cumulative independent foreground interventions.** Skills and scenes are bounded, but successive individually valid actions have no actor-wide interference budget. Add a shared rolling duration/movement/interruption ledger in `actions.py` and adapter `CommandController.cs`; test alternating action IDs and repeated scenes cannot reset the budget.

9. **G9 — High, supplementary privacy gap: forgetting a memory is narrower than erasing a conversation.** An in-memory probe confirmed source words remain in profile export after memory deletion; general-recall paraphrases also lack derivation links. Add an explicitly scoped conversation-erasure operation in `storage.py`/`admin.py`, and record retained recall dependencies in `social.py`; test deletion/export/replay/paraphrase behavior in `test_storage.py` and `test_social_replay_erasure.py`. Actor-local forgetting must preserve the distinction from erasing other actors' independently heard experiences. This is a privacy limitation, not a claim that agent-design explicitly requires a conversation-erasure API.

**Scope:** role, memory and storyline protections apply to v1. NPC-to-NPC conversation, social initiatives, learning between NPCs and the complete demonstrated learning cycle are post-v1. Service-limited integrations are P1 in the main spec. Missing live group conversations, teaching and neighborhood embodiment are therefore not counted as missing alpha features. No native price, mission-objective, reward, faction or canonical-relationship setter was found in the reviewed action/skill/neighborhood paths; that does not excuse G1–G3.
